# カロリー管理アプリ

日々の食事と体重を記録するカロリー管理アプリです。Muse のスペース（Webアプリ）として動作します。

## 機能

- 日付ごとに朝食・昼食・夕食・間食を記録
- 目標カロリーに対する残量をプログレスリングで表示し、PFC（たんぱく質・脂質・炭水化物）の内訳も確認できます
- 体重の記録と推移の確認
- 食品マスター：入力した食品は自動でマスターに登録され、表記ゆれなどの重複は自動で避けられます
- 各食事区分の直近3件を履歴からワンタップで再記録
- マスター管理画面（右上の歯車アイコン）：マスターの追加・編集・削除、検索と並び替え
- 分量入力：1食分／半分のプリセットに加え、小数分はスライダー（0.1〜2.0、0.1刻み）、整数分は＋／−ボタンで追加でき、合計で最大10食分まで指定できます。マスターには1食分基準で保存し、記録時に分量へ換算します
- 写真で記録：写真からAIが料理名・カロリー・PFCを推定し、内容を編集してから記録できます。解析は途中で取りやめでき（30秒で経過表示、90秒で自動取りやめ）、写真自体は保存されません

## 技術構成

- TypeScript / React（クライアント）＋サーバーアクション
- SQLite（Drizzle ORM）：テーブルは meals / settings / weight_logs / master_foods
- Bun ベースのランタイム

## データについて

このリポジトリに含まれるのはソースコードのみです。食事・体重の実データ（app.db）は含まれません。
